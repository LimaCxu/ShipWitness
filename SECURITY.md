# Security policy

ShipWitness is under active development. Do not expose the current `0.x` release directly to the public internet: authentication and tenant isolation are not implemented yet.

Please report vulnerabilities privately through GitHub Security Advisories. Do not include real customer data, credentials, repository contents, or production URLs in a report.

Supported versions:

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| < 0.2 | No |
