# 验收凭据保险箱

管理员可在“工作区管理 → 集成 → 验收凭据保险箱”保存测试环境账号、密码或令牌。凭据值使用 `SHIPWITNESS_MASTER_KEY` 加密落库，保存后界面和 API 都不会再次返回明文或密文。

在验收标准的“填写内容”步骤中输入 `{{secret:LOGIN_PASSWORD}}` 即可引用。合同、任务快照、审计、截图说明和签名卷宗只记录 `LOGIN_PASSWORD` 这个引用名；执行器仅在运行期间把明文交给浏览器，运行完成后不持久化。

安全边界：

- 仅工作区管理员可创建、查看名称和删除凭据。
- 使用独立、低权限、可随时轮换的测试账号，不要保存生产管理员凭据。
- 删除或改名后，引用旧名称的任务会安全失败并提示凭据不存在。
- 轮换 `SHIPWITNESS_MASTER_KEY` 时，凭据会与签名私钥、Webhook、邮件和 MFA 密钥一起重新加密。
